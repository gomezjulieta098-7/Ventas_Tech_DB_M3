# RetailPro – Proyecto de Data Analytics

## ¿De qué trata el proyecto?

Este proyecto es parte de mi curso de Data Analytics. Trabajamos con una empresa ficticia llamada RetailPro, que vende productos tecnológicos.

El objetivo principal es analizar la disminución de las ventas, identificando en qué regiones y períodos se producen las caídas. También buscamos conocer qué productos generan más ingresos y cómo compran los clientes.

## Herramientas utilizadas

- **SQL:** para consultar y analizar los datos.
- **Power Query:** para limpiar y organizar los datos.
- **Power BI:** para trabajar con el modelo de datos, crear medidas y analizar las ventas.
- **GitHub:** para guardar los archivos del proyecto.

## Trabajos realizados

- **M1 y M2:** planteamos el problema de negocio y diseñamos el modelo de datos.
- **M3:** creamos la base de datos y las tablas en SQL.
- **M4:** realizamos consultas para analizar ventas, productos y clientes.
- **M5:** trabajamos con consultas SQL utilizando JOIN.
- **M6:** limpiamos y transformamos datos con Power Query.
- **M7:** trabajamos en la presentación y comunicación de los resultados.
- **M8:** creamos relaciones, una tabla calendario y medidas DAX en Power BI.
- **M9:** utilizamos IA para revisar consultas, analizar resultados y mejorar la documentación.

## ¿Cómo ejecutar las consultas SQL?

1. Abrir el programa utilizado para trabajar con la base de datos SQL.
2. Ejecutar primero los scripts de M3 para crear las tablas y cargar los datos.
3. Ejecutar los archivos de datos adicionales de M4, si todavía no están cargados.
4. Abrir los archivos `.sql` de M4 y M5.
5. Ejecutar las consultas y revisar los resultados.
