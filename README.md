Módulo 3 – Creación de la base de datos

Módulo 4 – Consultas SQL de negocio: Se amplió la tabla ventas con datos simulados de 2024 y 2025 para analizar la evolución de la facturación, los productos más vendidos y los clientes recurrentes.
La orden de ejecución seria: 
1) Ejecutar el archivo SQL del M3 para crear la base de datos
2)Ejecutar m4_datos_adicionales.sql para incorporar las ventas adicionales.
3)Ejecutar m4_consultas_negocio.sql para obtener los resultados.

El archivo M4 Consultas SQL de Negocio.pdf contiene el análisis y las conclusiones de las consultas realizadas.
